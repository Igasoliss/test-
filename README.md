# Solís Media

Sitio web (landing) de Solís Media. HTML y CSS puros, sin WordPress ni dependencias.
Abre `index.html` en el navegador y se ve completo.

## Estructura
- `index.html`: la página.
- `css/styles.css`: colores, tipografías y diseño.
- `assets/img/`: foto de Ignacio y favicon.
- `assets/fonts/`: tipografía Poppins (incluida, no depende de Google).

## Publicar gratis con GitHub Pages
1. En el repositorio: Settings > Pages.
2. Source: Deploy from a branch. Branch: `main`, carpeta `/ (root)`. Guardar.
3. En unos minutos la página queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
4. Para usar solismedia.cl: en Settings > Pages escribe el dominio en "Custom domain" y configura el DNS en NIC Chile según la guía de GitHub ("Managing a custom domain for your GitHub Pages site").
